# 小宇和乐乐的猫咪小窝

这里仅托管静态网页外壳。共同内容由 Supabase 保存，仅限两个指定账号登录后访问。

线上地址：https://qing070602.github.io/xiaoyu-lele-memory-site/

使用自己设置的邮箱和密码登录，可在网页中添加或修改时间线、上传照片、修改照片说明及共同情书。右上角按钮刷新内容或退出。

不要向此仓库提交私人照片、数据库导出、密码、service_role 密钥或其他管理凭据。config.js 中的 publishableKey 为公开客户端使用，数据访问由数据库和文件存储的权限规则控制。

原创猫咪与占位插画为 SVG。Lucide、ZCOOL KuaiLe、Mali 及 Supabase 官方客户端的开源许可证随 assets 一起保留。
